# Pequlieer

**You need it. We connect it.**

Pequlieer is a Cape Town service-connection and coordination business. The website helps customers describe the service they need and express interest as a potential service provider.

## Website pages

- `index.html` — homepage, service search, categories, process and FAQs
- `request.html` — customer enquiry form that prepares a WhatsApp message
- `join.html` — provider interest form that prepares a WhatsApp message
- `privacy.html` — privacy notice
- `style.css` — shared site styles
- `favicon.svg` — site favicon

## Enquiry behaviour

The website is static. Forms do not submit to a database or send automatically. They prepare a message for WhatsApp; the visitor must review and press **Send**. If WhatsApp does not open automatically, the form provides a fallback link to the prepared message.

## Deployment

The site can be hosted on GitHub Pages, Netlify or another static host. After changes are committed, allow the host time to deploy and verify the live site on desktop and mobile.

## Operational reminders

- Keep the public privacy notice aligned with the actual data-handling process.
- Share customer details with a provider only when appropriate and with the customer's agreement where needed.
- Assess provider reliability and relevant experience consistently; do not promise availability or a confirmed booking before arrangements are agreed.
- Keep internal enquiry and job records private and access-limited.
- A static WhatsApp form does not provide a central submission log. If enquiry volume grows, consider a proper form service or backend with suitable privacy and security controls.
